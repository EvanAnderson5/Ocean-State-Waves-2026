# Ocean-State-Waves-2026
Creation of pitcher statistics using Trackman batted-ball data. Additional xWOBA modeling using launch angle and exit velocity.

*Note: Due to rules with proprietary Trackman data in the NECBL, the following project uses an example CSV. The true CSV was used to find all these metrics initially, before being sent to our director of analytics. This project only demonstrates my thought process behind this project and the necessary code.
